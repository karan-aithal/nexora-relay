## Contributing

Please follow these guidelines when contributing:

- Open issues for non-trivial changes first.
- Use feature branches; target `main` via PR.
- All PRs must pass CI: build, tests, lint, and security checks.

### Commit messages

We use Conventional Commits. Examples:

- `feat(site-controller): add health endpoint`
- `fix(emv): correct tlv parsing bug`

### Code style

Run `pre-commit install` to enable hooks locally.
